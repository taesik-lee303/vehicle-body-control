시간은 시뮬레이션 시각입니다. 일시정지 중에는 시각이 흐르지 않아 수신 중단(C4)도 생기지 않습니다. 전조등·와이퍼·잠금·경고는 모두 C 코어(vbc_step)의 출력을 그대로 그립니다.

도로는 세종대학교 주변 실제 도로와 지형입니다. 주행 모드에서는 핸들을 직접 돌려야 커브·교차로를 돌고, 건물에 부딪히면 멈출 때까지 브레이크가 걸립니다(후진 R으로 빠져나오기). 속도를 직접 입력하거나 시나리오를 재생하면 순환로(능동로 → 광나루로 → 군자로 → 천호대로, 약 2.9 km)를 자동으로 따라갑니다. 지도 데이터 © OpenStreetMap contributors. 주소 끝에 ?map=straight를 붙이면 예전 직선 도로입니다.
