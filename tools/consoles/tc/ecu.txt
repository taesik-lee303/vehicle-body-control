# BCU 전체(ECU) 테스트 케이스 (make con-ecu: 와이퍼 → 조명 → 도어 → 계기판을 vbc_step과 같은 순서로 실행)
# 모듈 TC가 볼 수 없는 SWC 간 상호작용만 시험한다: L6 와이퍼→조명, D5 경고 우선순위, C4 수신 중단 시 SWC 4개 동시 반응.
# 시작 상태: 시동 OFF, 기어 P, 속도 0, 조도 30000, 강우 0, 스위치 OFF, 도어 닫힘. 주기 신호는 50ms마다 자동 송신.
# 기대값은 사양서 VBC-SRS-001 v1.0 4장(C1~C5), 5.1(L1·L3·L4·L5·L6), 5.2(W1~W5), 5.3(D1·D3·D4·D5).
