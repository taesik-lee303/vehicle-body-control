# 모듈별 테스트 콘솔

도어·계기판·조명·와이퍼 모듈을 **하나씩 따로** 실행해 보는 대화형 콘솔입니다.
메뉴에서 입력값을 바꾸면 그 모듈의 `step` 함수만 호출해, 출력이 어떻게 바뀌는지 바로 보여 줍니다.
다른 모듈은 실행하지 않으므로 그 모듈 코드만 확인할 수 있습니다.

```bash
make con-doors       # 도어·잠금 D1~D3
make con-dashboard   # 계기판 경고 D4·D5
make con-lighting    # 조명 L1~L6
make con-wipers      # 와이퍼 W1~W5
make consoles        # 4개 모두 빌드만 (build/con_*)
```

## 화면 읽는 법
```
== 도어·잠금 (D1~D3) ==  시각 0.000초
  [출력] 도어 풀림 |                                       ← 이 모듈의 출력
  [판정] 수신 중단 아니오 | 시동 켜짐 | 유효한 속도 14 km/h  ← 모듈이 실제로 받는 값 (C2~C4 반영)
  [입력 바꾸기]
    1) 시동 [ON] (누르면 전환)
    2) 기어 [D]
    3) 속도 [14 km/h] (유효 0~250)
    4) 속도·기어·시동 송신 [보내는 중] (누르면 끊기/잇기, C4)
  [시간·기타]  t) 시간 진행   r) 처음 상태로(C5)   h) 도움말   q) 종료
선택> 3
  속도 km/h (범위 밖 값도 됨, 예: 300)> 15
  → [  0.000s] 도어: 풀림 → 잠김                           ← 바뀐 출력과 시각
```
- 번호로 입력을 고릅니다. 시동과 송신 끊기는 누를 때마다 전환됩니다. 보기는 번호나 이름(예: `D`, `AUTO`, `저속`, `FL`)으로 고릅니다.
- **시간은 `t`로만 흐릅니다.** 0.05초 단위로 입력합니다(예: `0.95`, `0.05`). 그동안 속도·기어·시동·조도·강우량은 0.05초마다 자동으로 다시 보내집니다(사양서 3.1).
- 범위 밖 값(속도 300, 조도 70000, 강우 101)도 그대로 보낼 수 있어 고장·무효 판정을 확인할 수 있습니다.
- 값을 묻는 곳에서 그냥 Enter를 누르면 취소됩니다.

## 규격 밖 값 넣기
모듈이 정해진 규격 밖의 값을 받았을 때 어떻게 동작하는지 확인할 수 있습니다.

| 입력 | 넣을 수 있는 값 | 넣을 수 없는 값 |
|---|---|---|
| 속도, 조도, 강우량 | 정수 전체(int32, 약 ±21억). 예: `-5`, `101`, `99999999` | 소수(`50.5`), 글자(`abc`), int32 밖 — 모듈 입력 형식이 정수라 넘길 방법이 없음 |
| 와이퍼 스위치 | "코드로 직접" 메뉴: 정수 아무거나. 0 OFF, 1 AUTO, 2 LOW, 3 HIGH, **그 밖의 값도 그대로 넘김** (예: `7`, `-1`) | 글자 |
| 조명 스위치 | "코드로 직접" 메뉴: 0 OFF, 1 AUTO, 2 ON, 그 밖의 값도 그대로 | 글자 |

정해진 값 밖의 스위치는 메뉴에 `정의 안 됨(7)`처럼 표시됩니다.

확인해 본 결과 (2026-10-07, develop 기준 코드)
| 콘솔 | 입력 | 동작 | 근거 |
|---|---|---|---|
| 와이퍼 | AUTO·강우 50%(저속)에서 스위치 코드 7, -1 | 저속 유지 (마지막 정상 값 AUTO로 계속 동작) | 팀 요구사항 SWR-W4-005 |
| 와이퍼 | HIGH에서 코드 99, 강우 99999999 | 고속 유지, 강우 고장 표시만 켜짐 | SWR-W4-005, 우선순위 W4 > W5 |
| 와이퍼 | 이어서 코드 1(AUTO) | 간헐 (강우 고장) | W5 |
| 조명 | ON(켜짐)에서 스위치 코드 7, 이후 조도 300·30000 | 켜짐 그대로 유지. L2·L3 시간은 AUTO일 때만 세므로 반응 없음 | 사양서·팀 문서에 정의 없음 (질의 후보) |

## 콘솔별 입력
| 콘솔 | 바꿀 수 있는 입력 | 확인할 출력 |
|---|---|---|
| `con-doors` | 시동, 기어, 속도, 속도·기어·시동 송신 끊기 | 도어 잠김/풀림 |
| `con-dashboard` | 속도, 조도, 강우량, 도어 4개, 차량 상태·조도·강우 송신 끊기 (시동 ON·기어 D로 시작) | 계기판 경고 |
| `con-lighting` | 시동, 조도, 조명 스위치, **와이퍼 단계(직접 지정)**, 차량 상태·조도 송신 끊기 | 전조등, 조도 고장 표시 |
| `con-wipers` | 시동, 속도, 강우량, 와이퍼 스위치, 차량 상태·강우 송신 끊기 (기어 D로 시작) | 와이퍼 단계, 강우 고장 표시 |

조명 콘솔은 와이퍼 모듈을 실행하지 않습니다. L6(와이퍼 10초 연속 작동 → 점등)은 메뉴의 "와이퍼 단계"를 직접 바꿔 확인합니다.

## 해 볼 만한 예 (기대 결과는 사양서에서 계산)
| 콘솔 | 입력 | 기대 결과 |
|---|---|---|
| 도어 | 시동 ON, 기어 D, 속도 14 → 15 → 5 | 15에서 잠김, 5에서도 잠김 유지 (D3) |
| 도어 | 잠긴 상태에서 송신 끊기 → `t 0.5` → 시동 OFF → 송신 잇기 | 끊긴 동안 잠김 유지(D1), 이으면 풀림(D2) |
| 계기판 | 문 FL 열림 → 속도 1 → 조도 70000 → 문 닫힘 → 강우 101 → 조도 30000 | 없음 → 도어 → 도어 → 조도 → 조도 → 강우 (D4, D5) |
| 조명 | 시동 ON, AUTO, 조도 300, `t 0.95`, `t 0.05` | 1.000초에 점등 (L2) |
| 조명 | 이어서 조도 30000, `t 2.95`, `t 0.05` | 3초 뒤 소등 (L3) |
| 조명 | AUTO, 와이퍼 단계 저속, `t 9.95`, `t 0.05` → 와이퍼 단계 정지 | 10.000초에 점등, 정지하면 바로 소등 (L6, C1) |
| 조명 | 스위치 OFF, 조도 70000 → 시동 OFF | 점등·고장 표시 → 소등, 고장 표시는 유지 (L5, L1) |
| 와이퍼 | 시동 ON, AUTO, 속도 30, 강우 9 → 10 → 40 → 70 → 속도 0 | 정지 → 간헐 → 저속 → 고속 → 저속 (W2, W3) |
| 와이퍼 | 강우 101 → 시동 OFF | 간헐·고장 표시 → 정지, 고장 표시는 유지 (W5, W1) |

파일로 입력을 넣어 기록을 남길 수도 있습니다: `./build/con_doors < 입력.txt > 결과.txt` (입력한 값도 결과에 함께 찍힙니다).
