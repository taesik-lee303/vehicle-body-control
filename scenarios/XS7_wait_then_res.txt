# 재출발 대기 (XS7, XD3): 3초 넘게 서 있으면 스스로 출발하지 않고, 앞차가 떠나면 "출발 가능"을 알린다. RES로 출발
adas on
drive on
ign on
gear d
obj add car 25 0 30          # 앞차 #1: 25 m 앞, 30 km/h
pedal 1 0
wait 3
pedal 0 0
sg on
sg set
expect sg active
wait 6
obj 1 speed 0 2              # 앞차가 선다 (13.2초)
wait 12                      # 자차는 20.2초쯤 정지 유지
expect sg hold
wait 3                       # 24.0초: 정지 3.8초
expect sg wait               # XS7
obj 1 speed 30 1.5           # 앞차 출발
wait 1.5
expect sg wait               # 스스로 출발하지 않음
expect sgalert go            # XD3 출발 가능
sg res
expect sg active
wait 3
expect moving on
