# X08 운전자 개입: 가속 페달은 잠깐 앞서고, 브레이크는 바로 해제, 70 km/h를 넘으면 시스템 해제와 개입 요청 (XS10, XS11, XR1)
#! at 2420
adas on
drive on
ign on
gear d
obj add car 25 same 30      # #1 앞차
pedal 1 0
wait 3
pedal 0 0
sg on
sg set
expect sg active
wait 2
pedal 1 0                   # 가속 페달: Stop & Go 요청은 쉬고 운전자가 앞섬
wait 1
expect sg active
pedal 0 0
wait 1
pedal 0 1                   # 브레이크
wait 0.05
expect sg standby           # XS10: 그 주기에 대기
pedal 0 0
wait 1
sg res
expect sg active
obj 1 del                   # 앞차를 지우고
sg up
sg up
sg up                       # 설정 60 km/h
pedal 2 0                   # 풀 스로틀로 70 km/h 넘김
wait 2.5
expect sg standby           # XS11: 70 km/h 초과 해제
expect sgalert takeover     # 개입 요청 5초
pedal 0 0
