# R1 시동이 꺼져 있으면 차는 움직이지 않는다. 시동은 정지 상태에서만 켜고 끌 수 있다.
# 전제: 주행 모델 ON, 초기 상태(시동 OFF, 기어 P)에서 시작
drive on
gear d
pedal 2 0
wait 3
expect speed 0          # 시동 OFF: 풀 스로틀이어도 정지
ign on
wait 1
expect speed 25         # 시동 ON: 풀 스로틀 25 km/h/s
ign off                 # 주행 중 시동 끄기 → 거부
expect ign on
pedal 0 1
wait 0.6
expect speed 1          # 25 - 40×0.6 = 1 km/h
wait 0.05
expect speed 0          # 0에서 멈춤
ign off                 # 정지 상태: 허용
expect ign off
