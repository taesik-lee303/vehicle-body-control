# R5 최고 속도는 전진 250 km/h, 후진 20 km/h. 가속 정도: 보통 +10, 풀 +25, 브레이크 -40, 타력 -5 km/h/s
drive on
ign on
gear d
pedal 2 0
wait 9.95
expect speed 249        # 248.75
wait 0.05
expect speed 250        # 250.00 도달
wait 5
expect speed 250        # 더 오르지 않음
expect rxlost off       # 250은 유효한 속도 (C3), 입력은 계속 송신 중
pedal 0 1
wait 6.25
expect speed 0
gear r
pedal 2 0
wait 0.7
expect speed 18         # 17.5
wait 0.1
expect speed 20         # 후진 최고 20
wait 3
expect speed 20
