# 레이더 끊김 (XC1, XM10, XS11, XC8): FR 새 프레임이 0.2초 없으면 고장, 맵 없음, Stop & Go 해제. 정상 프레임 1초 뒤 복귀
adas on
drive on
ign on
gear d
obj add car 25 0 30          # 앞차 #1: 25 m 앞, 30 km/h
pedal 1 0
wait 3
pedal 0 0
sg on
sg set
expect sg active
wait 5                       # 8.000초: 마지막 프레임
radar fr cut
wait 0.15
expect fr ok                 # 0.15초
wait 0.05
expect fr fault              # 0.20초 (XC1)
expect map none              # XM10
expect sg standby            # XS11
expect sgalert takeover
radar fr ok                  # 8.25초부터 다시 프레임
wait 1
expect fr fault              # 9.20초: 아직 복귀 전 (XC8)
wait 0.05
expect fr ok                 # 9.25초: 1초 연속
expect map ok
