# R3 D에서 가속하면 속도가 오르고, R에서 가속하면 후진한다. P·N에서는 움직이지 않는다.
# (후진도 속도는 방향 없는 속력으로 표시하고 기어 R로 구분한다 — 사양서 3.1)
drive on
ign on
pedal 1 0
wait 3
expect speed 0          # P: 가속해도 정지
gear n
wait 3
expect speed 0          # N: 가속해도 정지
gear d
wait 1
expect speed 10         # D: +10 km/h/s
pedal 0 1
wait 0.25
expect speed 0
gear r
pedal 1 0
wait 1
expect speed 10         # R: 후진 가속 (속도 10, 기어 R)
expect gear r
