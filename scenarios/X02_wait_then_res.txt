# X02 재출발 대기: 3초 넘게 서 있으면 스스로 출발하지 않고 '출발 가능'을 알린 뒤 RES로 출발 (XS7, XD3)
#! at 2420
adas on
drive on
ign on
gear d
obj add car 25 same 30      # #1 앞차: 25 m 앞, 내 차로, 30 km/h
pedal 1 0
wait 3
pedal 0 0
sg on                       # Stop & Go 스위치 (XS1)
sg set                      # 지금 속도로 작동, 설정 30 km/h (XS2)
expect sg active
wait 6
obj 1 speed 0 2
wait 12
expect sg hold
wait 3                      # 정지 3.8초
expect sg wait              # XS7 재출발 대기
obj 1 speed 30 1.5
wait 1.5
expect sg wait              # 앞차가 떠나도 스스로 출발하지 않음
expect sgalert go           # XD3 출발 가능
sg res                      # RES (화면: F)
expect sg active
wait 3
expect moving on
