# 측면 레이더 고장 (XS13): FCL이 가려지면 작동은 계속하지만, 멈춘 뒤에는 스스로 출발하지 않고 RES를 기다린다
adas on
drive on
ign on
gear d
obj add car 25 0 30          # 앞차 #1: 25 m 앞, 30 km/h
pedal 1 0
wait 3
pedal 0 0
sg on
sg set
expect sg active
wait 5
radar fcl block
wait 0.1
expect fcl fault
expect map reduced
expect sg active             # 작동은 계속
wait 1
obj 1 speed 0 2
wait 12
expect sg wait               # 3초 전이라도 재출발 대기
obj 1 speed 30 1.5
wait 1.5
expect sg wait               # 스스로 출발하지 않음
sg res
expect sg active
