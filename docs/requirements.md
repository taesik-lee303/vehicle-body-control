# 요구사항 추적표 (VBC-SRS-001 v1.0)

근거: [사양서 PDF](spec/VBC-SRS-001_v1.0.pdf). 증명 결과는 [verification.md](verification.md)에 같은 ID로 기록한다.

## 공통 (C) — 필수
| ID | 요약 |
|---|---|
| C1 | "N초 연속": 조건이 깨지면 처음부터 다시 셈. L2·L3는 시동 ON + AUTO + 조도 정상일 때만, L6는 시동 ON + 와이퍼 작동 중에만 셈. 상위 규칙이 전조등을 정하는 동안에도 계속 셈 |
| C2 | 센서 고장: 0.5초간 미수신 또는 범위 밖. 첫 수신 전에는 시작 시점부터 0.5초. 정상 값이 오면 복귀 |
| C3 | 유효한 속도: 속도·기어·시동 각각 마지막 수신 0.5초 이내 + 속도 0~250 |
| C4 | 속도·기어·시동 중 하나라도 0.5초 미수신이면 "수신 중단" → 조명·와이퍼는 시동 OFF로 간주 |
| C5 | 초기 상태: 소등, 와이퍼 정지, 잠금 해제, 경고 없음 |

## 조명 (L) — 필수, 우선순위 L1 > L5 > L4 > L6 > L2·L3
| ID | 요약 |
|---|---|
| L1 | 시동 OFF → 소등 |
| L5 | 조도 센서 고장 → 점등 + 고장 표시(시동 무관) |
| L4 | 스위치 ON 점등 / OFF 소등 |
| L6 | AUTO: 와이퍼 10초 연속 작동 시 점등, 작동 중 유지 |
| L2 | AUTO: 조도 < 1000 lux 1초 연속 → 점등 |
| L3 | AUTO: 조도 > 1500 lux 3초 연속 → 소등. 어느 규칙도 정하지 않으면 직전 상태 유지 |

## 와이퍼 (W) — 필수, 우선순위 W1 > W4 > W5 > W2·W3
| ID | 요약 |
|---|---|
| W1 | 시동 OFF → 정지 |
| W4 | OFF 정지 / LOW 저속 / HIGH 고속 |
| W5 | AUTO + 강우 센서 고장 → 간헐. 고장 표시는 시동·스위치 무관 |
| W2 | AUTO: <10% 정지, 10~40% 간헐, 40~70% 저속, ≥70% 고속 |
| W3 | AUTO + 유효한 속도 0 → W2 결과를 한 단계 낮춤 |

## 도어·잠금·경고 (D) — 필수
| ID | 요약 |
|---|---|
| D1 | 수신 중단(C4) → 잠금 상태 유지 |
| D2 | 그 외 시동 OFF 또는 기어 P → 해제 |
| D3 | 그 외 유효한 속도 ≥ 15 → 잠금. 해당 없으면 직전 유지 |
| D4 | 유효한 속도 > 0 + 문 하나라도 열림 → "주행 중 도어 열림" |
| D5 | 경고 하나만: 주행 중 도어 열림 > 조도 센서 고장 > 강우 센서 고장 |

## 선택
| ID | 요약 |
|---|---|
| R1~R5 | 주행(시동·기어·가속·브레이크·최고속도). 안 하면 속도·기어·시동 직접 입력 |
| X1~ | 팀 추가 기능. 구현 전에 사양서와 같은 형식(ID, 조건, 동작, 수치)으로 요구사항부터 작성 |
