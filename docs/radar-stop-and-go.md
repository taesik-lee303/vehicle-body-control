# 전방 레이더 맵 · Stop & Go (실험 브랜치 `exp/radar-stop-and-go`)

필수 과제(VBC-SRS-001)와 별개로 해 보는 실험이다. 요구사항은 [`docs/radar-requirements.md`](radar-requirements.md)(원본: Claude Docs 문서 "전방 레이더 맵·Stop & Go 요구사항 (가정)")에 있고, ID(XC·XM·XS·XR·XD·XH)는 그 문서를 따른다.
레이더 하드웨어 3개를 **센서 모델**로 소프트웨어 안에 만들고, 그 출력(검출점 프레임)만으로 전방 맵을 만들어 선행 차량을 따라 서고 출발한다. 터미널과 브라우저 시뮬레이터 둘 다에서 돈다.

## 구조

```
[시뮬레이터 세계]  env_world.c    교통 참여자·고정 물체 (정답). 화면이 그리고, 센서 모델이 "본다"
        │
[가상 하드웨어]    env_radar.c    레이더 3개: 시야·거리, 산란점, 검출 확률(RCS·거리⁴), 가림, 잡음, 분해능 병합,
        │                         가드레일·노면 클러터, 고장 주입(끊김·반복·고착·가림)
        ▼  radar_frame.h  ← 하드웨어/소프트웨어 경계: 50 ms 프레임 (카운터, 상태, 검출점 거리·방위·고도·도플러·SNR)
[제품]             adas_map.c     XC 프레임 유효성(새 프레임 0.2초, 반복, 고착 1초, 복귀 1초)
                                  XM 좌표 변환·노면 점 제거 → 군집화 → 추적·융합(α-β) → 높이·정지 분류 → 선행 차량
                   adas_stopgo.c  XS 상태 기계(꺼짐·대기·작동·정지 유지·재출발 대기), 추종 제어, 재출발 금지, 해제
                   drive.c        XR1·XR2 가속도 요청·정지 유지 (브레이크 > 가속 페달 > 정지 유지 > 요청 > 자연 감속)
```

- 제품 코드(`adas_*`)는 `radar_frame.h`와 `VbcContext`(C3·C4)만 본다. 센서 모델이나 세계를 직접 보지 않는다.
- 기존 C·L·W·D·R 모듈은 그대로다. `adas on`을 켰을 때만 동작하고, 꺼져 있으면 기존 동작·테스트와 같다.
- 같은 시나리오는 항상 같은 결과를 낸다 (센서 모델의 잡음은 시드 고정 의사난수, XH6).

| 파일 | 내용 |
|---|---|
| `src/radar_frame.h/.c` | 프레임 형식, 장착 정보·제원 (요구사항 8.1), 검출점 유효 범위 (XC3) |
| `src/env_world.h/.c` | 시뮬레이터 세계: 승용차·트럭·보행자·육교·문형 표지판·맨홀 (8.3) |
| `src/env_radar.h/.c` | 레이더 센서 모델 (XH1~XH8) |
| `src/adas_map.h/.c` | 전방 맵 (XC1~XC8, XM1~XM10) |
| `src/adas_stopgo.h/.c` | Stop & Go (XS1~XS13), 계기판 알림 (XD1~XD3) |
| `src/console.c` | `adas`, `obj`, `radar`, `sg`, `tracks` 명령과 `expect` 항목 |
| `src/sim_api.c` | 브라우저용 `sim_adas()`(JSON), `sim_points()`(검출점 float 배열) |
| `sim/js/scene/traffic.js` | 세계 물체 3D 모델 |
| `sim/js/scene/radar-view.js` | 검출점·시야·트랙·선행 차량을 3D 장면에 겹쳐 그림 |
| `sim/js/radar-panel.js` | 위에서 본 전방 맵 패널, 레이더 상태 칩 |
| `tests/test_radar.c`, `tests/test_stopgo.c` | 경계값 단위 테스트 |
| `scenarios/X00~X08*.txt` | 종합 데모와 요구사항별 시나리오 (터미널 `make scenarios`, 화면 시나리오 목록. `#! at 2420` = 지도 모드 출발 지점) |

## 실행

```bash
make test          # 기존 테스트 + test_radar + test_stopgo
make scenarios     # 기존 7개 + 레이더·Stop & Go 10개
source ~/emsdk/emsdk_env.sh && make sim    # 브라우저 http://localhost:8080/sim/
```

화면 (`adas on`은 시작할 때 자동):
- 툴박스 **교통 장면**: 정체 행렬, 끼어들기, 보행자 횡단, 육교·맨홀. **앞차** 멈춤/출발로 정체를 만든다.
- **Stop & Go**: `G` 스위치 → 속도를 올리고 `S` SET. 서면 3초 안에는 스스로 출발, 넘으면 `F` RES.
- **레이더 고장 주입**: 레이더마다 끊김·프레임 반복·값 고착·가림.
- 점 색: 하늘색 FR, 연두 FCL, 주황 FCR (어두운 점 = 정지 점, 회색 = 노면 점). 상자: 노랑 선행 차량, 빨강 경로 안 장애물, 흰색 장애물, 회색 무시(육교·표지판·맨홀).
- 오른쪽 **전방 맵** 패널을 누르면 보기 거리 40 / 80 / 150 m.

터미널 예:
```
adas on
drive on
ign on
gear d
obj add car 25 0 30      # 25 m 앞, 내 차로, 30 km/h
pedal 1 0
wait 3
pedal 0 0
sg on
sg set
obj 1 speed 0 2          # 앞차가 선다
wait 12
expect sg hold
expect gap 3 5           # 실제 거리 4.0 ± 1.0 m (XS5)
tracks                   # 맵의 확정 트랙
show
```

## 구현하면서 바뀐 것 (요구사항 문서 9장에도 반영)

시나리오를 돌려 보며 처음 정한 요구사항·설계가 틀린 곳을 찾았다. AI가 처음 제안한 값이 그대로는 맞지 않았던 사례다.

| 처음 | 무엇이 틀렸나 (증거) | 바꾼 것 |
|---|---|---|
| XS12 TTC 2.0초 미만이면 충돌 위험 | 목표 거리(4 m + 1.5초 × v)에서 멈춘 차에 다가가면 TTC = 1.5 + 4/v ≈ 1.98초 → 정상 감속 중 급제동, 11.9 m 앞에서 섬 | TTC 1.5초 미만(해제 2.5초). 필요 감속 > 3.5 m/s² 조건은 그대로 |
| 군집화 y 기준 1.0 m 고정 | 측면 레이더(분해능 2°)가 31 m 앞 차 하나를 두 군집으로 쪼갬 → 트랙 2개, 선행 차량이 오감 | y 기준 = max(1.0 m, 방위 분해능 1.5칸 × 거리). 같은 레이더 군집이 한 트랙에 겹치면 합침 |
| 가로 속도 = 위치 변화 × 0.05 + 감쇠 0.9 | 정상 상태에서 실제의 0.55배 (1.2 m/s 보행자 → 0.6) → 횡단 보행자를 못 막음 | 표준 α-β (β 0.1, 감쇠 없음) |
| x 속도 = 도플러 / cos | 옆으로 걷는 보행자의 가로 이동이 x 속도로 들어감 (−1.5 m/s) | vr = vx·ux + vy·uy에서 가로 몫을 빼고 구함 |
| 노면 점 제거 없음 | 저속에서 서 있는 앞차와 바로 앞 노면 잡음의 도플러가 같아 한 군집 → 트랙이 1.3 m 튀고 급제동 | FR 정지 점 중 z < 0.15 m + 고도 잡음 3σ는 군집에서 뺌 (4D 레이더의 높이 활용) |
| 높이 거르기 = 정지·한 번도 안 움직인 것만 | 넓은 육교·표지판이 조각나면서 조각마다 가짜 가로 속도 → "움직였음" → 장애물 → 가짜 선행 차량 | 바닥 2.5 m 이상은 움직임과 관계없이 장애물 아님 (밑으로 지나갈 수 있음). 폭 3 m 넘는 트랙은 가로 속도를 안 봄 |
| 연관은 x·y만 | 육교 아래 서 있는 차의 점이 위 육교 트랙에 붙음 | FR 측정은 높이 범위(±1.0 m)가 겹칠 때만 연관, FR 군집화에도 높이 차 1.0 m |
| 측면 레이더 정지 물체 = 장애물 | 측면 레이더의 노면 잡음이 우연히 3주기 이어져 5.6 m 앞 가짜 장애물 | FR 시야 안인데 FR이 한 번도 못 본 측면 정지 물체 = 측면 오검출. 확정 전 트랙 게이트를 좁힘 (x 1.0, y 0.3 m) |
| (위 규칙) | 맨홀을 0.6 m 앞에서 지날 때는 FR 시야(아래 15°) 밖이라 측면만 봄 → 한 주기 장애물 | 한 번 "무시"로 판정된 정지 물체는 정지해 있는 동안 유지 |
| XS9 (1) 선행 차량이 아닌 장애물 | 보행자가 경로에 들어오면 보행자가 선행 차량이 되어 RES가 통과 | 정지할 때 앞에 있던 차량이 아닌 장애물 |
| 정지 판정 = 속도 0이고 요청 ≤ 0 | 재출발 첫 주기는 변화율 제한 때문에 요청이 0 → 바로 다시 정지, 50 ms마다 오감 | 작동 0.5초 뒤부터, 변화율 제한 전 목표값으로 판단 |
| 추종 이득 0.25 / 0.8 | 과감쇠(시정수 3.6초): 멈춘 차 앞 14 m에서 한참 기어감 | 0.45 / 0.7 + 정지 모드 (앞차가 서 있고 3 m/s 미만이면 4 m에서 서는 감속도, 마지막 0.7 m는 −0.8 m/s²) |
| 센서 모델: 산란점 24개를 격자에서 건너뛰어 뽑음, 바닥면 포함 | 큰 수평면(육교 10 × 30 m)이 점 간격 2 m 넘게 성겨 조각남 | 64개, 간격을 넓혀 고르게. 아래에서 보는 바닥면은 넣지 않음 (정반사) |

## 실제 지도 시뮬레이션과 함께 (`exp/sim-realism`)
`exp/sim-realism`은 실제 도로 지도(세종대 주변) 시뮬레이션 위에 이 기능을 합친 브랜치다. 레이더는 실제 2D 기하로 계산한다.
- 화면이 C 세계에 **주행 경로 폴리라인과 점마다 차로 범위**(같은 방향 차로의 오른쪽·왼쪽 끝, 반대 차로 끝, 차로 폭)를 한 번 넘긴다 (`sim_set_path`). 차로 범위는 지도의 도로 폭·차로 수·일방통행으로 `city.js laneTable()`이 계산한다.
- 교통 차량은 C 세계에서 그 경로를 따라 달리고, 가로 위치는 그 자리의 차로 범위 안으로 제한된다. 도로가 좁아지면 남은 차로로 합류한다 (차선 이탈 없음). 반대 방향 차는 반대 차로가 있을 때만 그 안에.
- 화면은 매 프레임 **자차 앞 범퍼 자세와 요레이트**를 넘긴다 (`sim_set_ego`). 직접 운전으로 좌·우회전해도 센서 모델은 그 자세로 물체(회전 상자)를 본다.
- 제품 쪽 경로 판정(XM8)은 요레이트로 예측한 곡선 경로(곡률 = 요레이트 ÷ 속도, y = 곡률 × x² / 2)를 쓴다. 굽은 길에서도 앞차가 경로 안으로 잡힌다. 직선 도로·터미널은 요레이트 0이라 예전과 같다.
- 교통 장면 프리셋은 그 자리에 실제로 있는 차로에만 차를 놓는다 (옆 차로가 없으면 건너뜀). `?scene=jam|cutin|ped|bridge`로 주소에서도 부를 수 있다.
- 실제 지도에는 가드레일이 없어 경로가 있으면 센서 모델의 가드레일 반사가 꺼진다 (`adas rail on|off`로 바꿀 수 있음).
- 한계: 교통 차량은 주행 경로를 따라서만 달린다 (교차로에서 다른 길로 꺾지 않음). 건물에 가리는 것은 센서 모델에 없다.

## 화면 사용
- **창 접기·크기**: 툴박스·이벤트 로그·전방 맵·미니맵·계기판 모두 머리의 ▾/▸로 접는다. 화면 안쪽 모서리 손잡이를 끌어 크기를 바꾸고, 두 번 누르면 기본 크기. 이 브라우저에 기억한다. `Tab`은 툴박스 접기.
- **교통 장면** (지금 자차 위치·속도 기준, 누르면 로그에 무엇을 보는 장면인지 한 줄 안내):

| 버튼 | 무엇을 하나 | 보는 것 |
|---|---|---|
| 정체 행렬 | 내 차로 앞 차 3대(30 km/h), 옆·반대 차로가 있으면 거기에도 | 앞차 멈춤/출발로 정체 → Stop & Go 정지·출발 (XS4~XS7) |
| 끼어들기 | 옆 차로 차가 나를 추월해 8 m 앞서면 내 차로로 | 0.3초 뒤 선행 차량 교체 (XM9). 옆 차로가 없으면 안내만 |
| 보행자 횡단 | 달릴 때: 길가 보행자가 내가 (속도 × 4.2초 + 정지 거리) 안으로 오면 건너기 시작. 서 있을 때: 바로 앞에서 건넘 | 속도를 줄이거나 섬 (XM9, XS5), 재출발 금지 (XS9) |
| 높이 거르기 | 맨홀·문형 표지판·육교와 그 아래 서 있는 차 | 4D 레이더 높이로 맨홀(낮음)·표지판·육교(높음)는 무시, 차에만 섬 (XM6) |

- **시나리오**: X00 종합 데모(정체 → 자동 출발 → 끼어들기 → 보행자 → 정지·RES, 약 75초), X01~X08 요구사항별. 지도 모드에서는 옆 차로가 있는 능동로(2.42 km 지점)에서 시작한다.

## 한계
- 전파 물리는 근사다: 재질 반사율은 종류별 RCS 고정값, 다중 반사·유령 표적은 없음.
- 조향 입력이 없어 직진 도로만 다룬다 (요구사항 Q2).
- 레이더 세 개가 같은 50 ms 시각에 프레임을 보낸다 (실제는 비동기).
- 실제 하드웨어와 연결하지 않는다. 다만 `radar_frame.h` 경계를 지키므로 입력부만 바꾸면 실제 레이더 프레임(CAN-FD·이더넷 디코딩)을 넣을 수 있다.
